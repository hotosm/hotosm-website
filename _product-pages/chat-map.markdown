Block 1:
  Section: What is it?
  Header: ChatMap is a user-friendly humanitarian mapping tool that utilizes WhatsApp to help communities share location data during emergencies. 
  Text: By allowing users to export their WhatsApp chat conversations, the tool extracts location information and associated messages to generate actionable maps. Designed for individuals with limited technical knowledge, ChatMap operates offline using GPS signals and requires no complex integrations, making it accessible and effective for those in disaster-affected areas. The open-source nature of the application encourages community collaboration and continuous improvement.

Block 3:
  Header: HOW DOES IT WORK?
  Highlight: ChatMap works by enabling users to export their WhatsApp chat conversations, which contain location data and messages.
  Text: Once the chats are uploaded to the ChatMap application, the tool processes this data to extract the relevant location information and displays it on a map. The application is designed to be straightforward, requiring no complex setups or business accounts. It operates offline by utilizing GPS signals for location tracking, allowing users to gather and send data even in areas with limited internet connectivity. Additionally, as an open-source tool, ChatMap invites community contributions for ongoing enhancements and improvements.<br><br> <strong>ChatMap + uMap!:</strong><br><br> - <u>Map Saving</u> Users can now save maps along with captured images, enhancing the functionality of ChatMap. <br> - <u>Location Sharing</u> Create a WhatsApp group for easy sharing of locations through text or picture messages. <br>- <u>Seamless Integration</u> Export the chat, upload it to <a href="http://chatmap.hotosm.org/">ChatMap</a>, and then download a .zip file for use with <a href="http://umap.hotosm.org/">uMap</a>. <br><br>
